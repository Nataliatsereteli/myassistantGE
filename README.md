# MyAssistant — сайт-визитка

Трёхъязычный статический сайт (русский, English, ქართული).
Сборка и публикация — GitHub Actions → GitHub Pages.

## Как поменять текст, цены и контакты

Ничего устанавливать не нужно — всё правится на github.com: открыть файл
в папке `content/`, нажать карандаш, поменять текст, нажать **Commit changes**.
Через 1–2 минуты сайт обновится сам.

| Что нужно | Файл |
|---|---|
| Цены | `content/pricing.yml` |
| Телефон, WhatsApp, Telegram, почта | `content/contacts.yml` |
| Тексты по языкам | `content/i18n/ru.yml` · `en.yml` · `ka.yml` |
| Домен, аналитика, блоки главной | `content/site.yml` |

Не загружайте через веб-интерфейс GitHub сканы документов, выписки и списки
клиентов: репозиторий публичный, и всё загруженное остаётся в истории.

## Что где лежит

```
content/            тексты по языкам, цены, контакты, настройки
templates/          HTML-шаблоны
assets/             стили, шрифты, иконки, картинки для соцсетей
build.py            генератор: читает content/, выдаёт готовый сайт
scripts/            шрифты, картинки, сборка переводов, проверки
.github/workflows/  автоматическая сборка и публикация
```

## Собрать локально

```bash
pip install -r requirements.txt
python build.py --serve   # соберёт в _site/ и поднимет http://localhost:8000
python build.py --check   # только проверить контент
python scripts/verify_build.py
```
